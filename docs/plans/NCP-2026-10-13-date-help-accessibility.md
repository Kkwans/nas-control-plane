# 日期范围操作提示的语义与键盘修正

## 问题与边界

`41a1ed8` 的 390px 普通字号和 200% 工件各保留一个 `region` moderate 违规：操作提示传送到 body，脱离已有 main。日期编辑器宽高、完整起止值的验收结论不变；普通截图中提示覆盖下一张卡片的上边框，不据此宣称标题文字被遮住。已有工件未记录提示关联和键盘撤销。

安装版本 Element Plus 2.14.3 支持 `append-to` HTMLElement。页头 `overflow: hidden`，因此不取消传送；现有 main 无该裁切。默认 hover 不覆盖单独聚焦，默认 Enter/Space 还会阻止按钮原生动作，默认 Escape 仅在提示内陷入焦点时处理。

## 有界实现

- 两个提示传送到控制组所属的现有 main；独立挂载回退到自身，不新增 landmark。
- 保留帮助正文、tooltip role、原生生成的 `aria-describedby`、可悬停内容和默认位置。
- hover/focus 同时支持，关闭请求与按钮焦点、按钮悬停、提示悬停共同仲裁；公开 popper DOM ref 覆盖提示内边距和箭头。
- 清空 tooltip 触发键，保留按钮原生 Enter/Space；Escape 取消待显示计时器并关闭，保持焦点，新的触发交互可重开。
- loading 同步禁用提示并清除交互状态，不依赖禁用按钮是否派发 blur；恢复后不复活旧焦点/悬停。
- 提示 DOM 和文档键盘监听均随组件卸载清理；不改日期弹窗、数据/API、全局样式或其他提示。
