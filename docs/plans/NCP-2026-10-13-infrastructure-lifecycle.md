# 基础设施页面生命周期隔离

日期：2026-10-13。范围：现有系统信息页的页面、认证会话与异步请求归属；不修改 NAS、网络配置协议或 DNS 产品操作流程。

## 问题与实现

详情与 DNS 读取结束后原先仅检查请求序号；卸载或认证更替不会使序号失效，因而旧响应可继续发布并启动 Mihomo 检查。DNS 确认、回滚结束后也可能在新认证上下文中发起复核读取。

页面固定捕获认证代次，并在会话 abort 或卸载时同步失效两个读取序号、取消所属详情/DNS/检查读取、注销手动刷新入口、清空详情与 DNS 草稿/预览/回滚标识并关闭弹窗。所有异步入口、成功/失败/最终清理及写后复核均检查页面归属；当前读取额外检查序号与信号，旧 finally 不清理新读取的 busy。

系统详情已有 signal 入参；DNS capability 与 Mihomo inspection 增加可选 signal 并原样透传，保留原 fetcher 参数和请求体。inspection 仍是既有 POST 检查，不是 DNS 写入。

客户端读取取消与 UI 观察失效不证明服务端操作取消或回滚。DNS 预览、确认、回滚保持既有请求，无自动重放，不因页面销毁宣称写入未发生；已发出的写操作结果仅禁止重新进入失效页面。

## 验证

24 项纯 fake Vitest：正常详情/检查/DNS 预览/确认/回滚；卸载与认证更替同步取消并清理；忽略 abort 的迟到成功/失败；刷新 latest-wins 和旧 finally；写入结束前或复核期间失效不得重读/重放；两个直接 fake-fetch 契约验证 signal、路径、POST 请求体与取消不重试。无真实浏览器、网络监听服务、子进程、Docker 或网络配置操作。

主任务对 HEAD 加本模块四文件的隔离副本独立复跑：62 文件 988 项单元、全量 ESLint、Vue 类型检查、生产构建及 540KiB 包预算全部通过。既有依赖复用，未启动浏览器或服务。CI 及浏览器回归仍待推送后验证。

## 保留边界

- 详情与 DNS 仍由同一个 Promise.all 等待；辅助 DNS 独立加载、失败状态与超时属于后续。
- 嵌套系统详情的入站校验属于独立后续，不以本次页面生命周期测试宣称响应契约完整。
- 同页 DNS 草稿修改、关闭/重开弹窗与手动刷新之间的 revision/弹窗代次竞争未在本次解决。
- 已提交 DNS 写入的未知结果、服务端持久化及真实 NAS 操作效果未验证；本切片不修改这些语义。
