# M20 用户账号移动布局

## 依据与边界

- 已查看 M19-A 的 390px / 100% 实际错误截图：账号名、状态和操作可见，最近登录与创建时间未显示；源码在窄屏对日期使用 `display:none`。
- 只调整 `UsersView.vue` 的账号模板与样式，保留读写请求、状态隔离、确认框、密码规则和现有操作。保留现有字体、颜色令牌与 Lucide 图标，不新增依赖。
- 桌面保留五列表格；1050px 以下有意采用完整信息卡片，避免读取账号日期时还需横向滚动。这是响应式信息架构选择，不声称已有 768px 截图证明了缺陷。

## 实现

1. 将两个日期单元改为有语义标签的元数据；桌面继续由表头标识，卡片显示“最近登录”“创建时间”。保留现有日期格式与“从未登录”回退。
2. 允许账号名与日期在必要处换行，不省略、不隐藏值；卡片采用可收缩网格，小于 480px 时账号名与状态分行。
3. 独立测试工作覆盖 64 字符英文长词、中文、已知/空日期，以及 320/390/768/1440px、100%/200% 根字体。实际浏览器只在经批准的 fixture CI 执行，本地不启动服务或浏览器。
