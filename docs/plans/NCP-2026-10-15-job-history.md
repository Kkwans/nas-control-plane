# 持久任务历史：只读分页方案

日期：2026-10-15。检查基线：`5284ef3`。状态：方案经主任务与独立审查确认；H0源码及隔离验证完成，待提交推送和远端CI；H1另行实现中，尚未验收。依据为后端审计 B05 / P1-A 的持久历史分页方向；这是独立后续，不重开已完成的 M15-B 最近任务首片。

## 目标与现有边界

让用户找到已经退出最近列表、但仍在 SQLite 中的任务。`job_engine.go` 启动只加载最近500条，`trimHistory` 淘汰可安全移出的终态；`list` 仅返回内存 registry。现有按ID读取不能帮助不知道ID的用户找回记录。`controlstore/jobs.go` 已有按创建秒与ID倒序的索引查询，但没有游标。新接口复用这两个索引，不改变现有 `/jobs`、单任务读取、SSE、下载观察或任务执行。

不做清理、保留期限、任务动作、重试、重放、审计身份补录、通知、导出、Agent制品查询或数据库迁移。历史不承诺永久保存，已有删除入口仍可能删除记录。

## H0：Store 与 HTTP 契约

新增已认证 `GET /api/v1/job-history`，使用独立静态路由。不要使用 `/jobs/history`，否则会遮蔽既有合法历史ID为history的单任务GET；旧 `/jobs/{jobID}` 行为保持不变。查询参数：

- `type`：省略或空串表示全部；非空按数据库原值精确匹配，不trim、不限定当前三种类型。UTF-8最多128字节，不接受控制字符。未知合法类型返回空页。
- `limit`：省略默认50；显式值仅接受十进制整数1–100，非法值返回400，不沿用旧接口的静默默认。重复的已知参数、未知参数均返回400，防止不同层解释不同。
- `cursor`：省略表示最新页；显式空值或非法编码返回400。原始RawQuery最多8192字节，使用 `url.ParseQuery` 解析且任何错误直接拒绝，禁止用会静默忽略坏转义/分号字段的 `URL.Query()`；参数总长度与游标长度先校验，再解析。

响应为 `{source:"persisted", items:[...], nextCursor?:string}`。没有total、页数或实时状态承诺。`nextCursor`仅在读取到额外一条时存在，锚点始终是本页最后一条已返回记录，不是额外行；空页无游标。响应 `Cache-Control: no-store`。

专用只读摘要 DTO 包含 `id/type/status/reference/message/error/errorCode/cancellationStatus/createdAt/updatedAt/completedAt`，字段沿用现有记录含义、时间格式与可选性。**不复用可操作的 JobSnapshot 类型**，不带 cancellable、persistenceStatus、artifactState、layers、速度或执行动作。SQL只投影所需列，不读取巨大layers_json再丢弃。错误信息仅来自既有已保存的安全字段，禁止拼接底层SQL/驱动错误。未知任务类型或状态保留原始纯文本标签，不映射成成功；DTO及OpenAPI的type/status使用开放字符串，不复用JobSnapshot的封闭枚举；缺失ID等不满足最小协议的记录使整页明确失败，不静默跳过并伪造连续历史。

摘要文本按UTF-8字节设置硬上限：id256、type128、status64、cancellationStatus64、errorCode128、reference4096、message8192、error8192。SQL对每个文本列使用 `CASE WHEN length(CAST(column AS BLOB)) <= cap THEN column ELSE NULL END` 等有界投影，并带独立超限标记；禁止先取完整字段到Go再检查，也不使用截断字符串作为正常值。NULL、非法UTF-8及既有协议必填字段缺失均按数据错误处理。所有用于返回或生成游标的行都验证；额外探测行只需有界取得排序键并验证，不能把额外行错误数据伪装成不存在。该策略限制返回Go的单字段数据，不承诺SQLite引擎读取/计算大字段时的内部峰值内存有硬上限。

完整UTF-8 JSON上限1 MiB（包含元数据与游标）；在发送200之前完成有界编码检查，超限整页返回503 `JOB_HISTORY_TOO_LARGE`并提示减少页大小，不截断单字段或跳过记录。文本列超限返回503 `JOB_HISTORY_CORRUPT`，减少页大小不能修复该记录。1 MiB限制最终响应字节，不是总堆内存上限；编码时另有已按字段/行数界定的DTO、单行JSON临时缓冲以及buffer扩容余量。不得把这些有限开销说成包含在1 MiB内，也不声称现有数据库所有内容合法。SQL投影和limit共同限制应用扫描量，编码预算再限制响应大小。

创建/更新时间必须可表示为合法RFC3339（UTC年份0000–9999）；完成时间保留既有零秒哨兵表示缺省，其余也须可表示。int64秒即使可解析也可能超出时间序列化范围，必须在生成JSON前检测并返回 `JOB_HISTORY_CORRUPT`，不能输出非法时间或部分200；游标锚点同样拒绝不可表示的秒值为400。

这里的status严格指最后一次成功保存的状态。正在运行或结果持久化待重试时，数据库可能仍显示queued/running；历史既不能据此证明仍在执行，也不能证明未执行。所有页面固定说明“仅显示最后保存的记录，可能落后于当前执行；不代表当前资源状态”，每条展示保存的更新时间。不得覆盖成内存状态，也不得生成看似已知的pending标志。原最近任务仍用于当前执行观察；两种来源不合并、不互相覆盖。重启恢复写入interrupted后，后续历史读取自然反映该已保存状态。

### 游标与顺序

游标为版本1的规范JSON经无padding的base64url编码，字段固定 `{v:1,type:"...",createdAtUnix:"...",id:"..."}`。创建秒使用int64十进制字符串，避免JS精度路径；排序值直接来自SQLite列，不用格式化后的HTTP时间反推。ID是原始非空文本，不强制当前随机hex形状，以兼容旧记录；UTF-8最多256字节且无控制字符。合法历史中若遇不可编码的排序键，整页返回历史数据错误，不截断或伪造游标。

游标最大2048字节，解码后最大1536字节；规范编码器关闭HTML转义（`SetEscapeHTML(false)`），固定字段顺序并移除编码器的末尾换行，使合法上限的引号、反斜杠、HTML字符及Unicode分隔符键均可往返，不因膨胀拒绝自己生成的游标。拒绝非规范base64url、非法UTF-8、未知版本/字段、重复JSON键、非规范或越界int64、尾随内容、空ID及type不一致。可通过解析后使用唯一固定字段顺序重新编码并比对原文，保证规范格式和拒绝重复键。type与请求逐字节一致，阻止跨筛选复用；limit不绑定，允许下一页调整大小。游标不是签名权限票据，无需保存密钥或服务端会话：已认证Root本来能浏览全部历史，篡改合法锚点最多改变浏览起点。

SQL按两种type条件与有无游标分成固定查询；有游标使用 `(created_at_unix,id) < (?,?)`，再 `ORDER BY created_at_unix DESC,id DESC LIMIT limit+1`。使用现有BINARY文本排序与参数绑定，禁止拼接输入。相同秒按ID严格递减，创建键在正常CAS更新中不可变。一次请求一条有界SELECT，不跨页持有事务。

这是向较旧记录移动的遍历，**没有跨页快照保证**：新插入且位于锚点之前的记录不会在后续页出现，需回到最新页；插入在锚点之后的记录可能出现；并发删除会使后续页变短或为空，锚点记录本身删除不妨碍继续；状态可以在两次读取间变化。不得把最后一页解释为“此后永远没有更多记录”。不提供偏移页码、跨页总数或后台补齐。

新增小型可选 history reader 接口，不把新方法强加到所有既有Job fake/provider。reader必须从实际活动的 `api.jobs.store` 获取；`Config.JobEngine` 可以自带与 `Config.ControlStore` 不同的store，不能读错另一份历史。返回slice及DTO由调用者独占，不持有可变共享缓存。没有持久store或provider不支持时返回501 `JOB_HISTORY_UNSUPPORTED`；存储读取失败/超时返回503 `JOB_HISTORY_UNAVAILABLE`；参数错误返回400 `JOB_HISTORY_INVALID_QUERY`；不可表示的历史记录返回503 `JOB_HISTORY_CORRUPT`。采用既有错误信封、请求context与有界store超时，不把不可用伪装为空历史。同步OpenAPI。

## H1：独立历史视图与兼容

在现有任务抽屉提供明确的“最近任务 / 已保存历史”切换，不增加一级导航。保留最近视图现有行为；非活动视图卸载其观察owner。历史使用独立composable、独立DTO解码，不复用取消或实时merge逻辑。

历史默认50条，可选20/50/100条，提供类型筛选、下一页和回到最新页；不提供假页数或默认全局关键词/状态搜索。类型控件提供现有已知类型、全部及当前页观察到的其他类型；另以一个普通文本输入支持未知类型精确查询，不为此引入新的可搜索选择器组件；查询能力仅限服务端type，不把本页搜索称全历史搜索。内存仅保留当前页和当前请求游标，不持续累积所有页面。显示“本页N条”，不暗示总量。

打开、切换类型或页大小、回到最新页均开始新的读取代次；改变页大小回到最新页，避免模糊页位置。下一页仅在当前成功页有nextCursor时可用；单飞且冻结type/cursor/limit；session、抽屉生命周期及请求generation共同验证成功、失败和finally归属。切换视图/关闭/登出中止读取并禁止迟到回写。页读取失败保留原页、原筛选标签和原游标，明确未切页；只允许重试同一只读请求。类型变化不能把旧页标成新类型，可清空并展示首次加载。历史不轮询、不订阅SSE，不触发Agent调用。

旧Server的404或501只显示“此服务暂不能提供已保存历史，可返回最近任务”，绝不自动把最近列表当全历史。401沿用会话失效；503是可重试读取失败；200坏信封是协议错误，不能视为不支持或空页。回到最近视图恢复原有观察能力，不让新接口失败阻断原功能。新Server兼容旧前端，无需同时部署。
