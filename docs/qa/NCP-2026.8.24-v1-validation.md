# NCP 2026.8.24-v1 验证记录

日期：2026-08-24
环境：`DH4300Plus` / `aarch64` / `/volume2/Project/nas-control-plane`

本记录对应本轮产品化收敛的已验证范围。NCP 仍按可信内网、登录后的 Root 控制面交付；本轮没有新增 MFA、RBAC、限流、复杂密码策略、CSP 或其他安全加固边界。

## 已交付

- 修复 system store 按资源维度的刷新并发，避免不同 scope 共用一个 Promise 时丢请求。
- 修复数据库表格中 `NULL`、空字符串和 bigint/decimal 文本值的展示与编辑语义。
- 统一 Monitoring 的共享 DTO，移除前端对内部字段副本的依赖。
- 使用 kin-openapi 做 OpenAPI 完整解析校验，并以 Go AST 检查注册路由与规格路径的 parity。
- 统一 `VERSION`、Compose `BUILD_VERSION`、镜像 tag、前端 package version 和 Go `--version` 为 `2026.8.24-v1`。
- 增加 GitHub Actions 核心门禁、Mock API Playwright Chromium 回归、Axe serious/critical 基线和 Compose config gate。
- 将 Infrastructure 首屏的网络、DNS、Tailscale、Mihomo 状态收敛为可读摘要；移动端系统分类改为可操作的 2×2 布局。
- 将导航元数据抽到 `frontend/src/router/navigation.ts`，修复 Element Plus `v-loading` 未注册造成的运行时警告。
- 将 `DockerImagePanel.vue` 中 Docker Hub 搜索、仓库详情、标签选择和拉取队列拆到 `DockerHubBrowser.vue`；父组件保留本地镜像和下载任务编排。
- 将 Docker 镜像、Docker Hub 和 Job API 从 `api/system.ts` 机械拆到 `api/docker.ts`；保留 system facade，Compose deploy 继续复用统一 Job 解析。
- Docker Mock API 增加本地镜像、Hub 搜索、标签、拉取任务和失败状态；Docker E2E 覆盖项目危险操作、Hub normal/empty/error、Axe 及四档 viewport screenshot regression。
- 为 Infrastructure 系统详情与 Mihomo 检查增加独立 request sequence gate；较早响应、错误和 finally 不再覆盖较新的刷新结果，并补充单元测试与延迟响应 E2E。
- 将 `api/system.ts` 的共享请求传输层抽到 `api/systemTransport.ts`；保留 `@/api/system` facade 和领域函数签名，后续仍需按领域继续拆分。
- Logs 历史查询接入服务端 `nextCursor`，并在界面明确单次最多 200 条；Docker 容器 bounded tail 没有历史游标时单独提示限制，补充 cursor E2E。
- 为 Database SQL 工作台增加 DROP/TRUNCATE/ALTER 及无 WHERE UPDATE/DELETE 的客户端风险提示与确认；取消确认不会发起 SQL 请求，提示不限制 Root 正常执行能力。
- 保留 Overview/System 的四档 viewport before/after 截图，并覆盖主要页面 desktop/mobile 正常导航与横向溢出检查。
