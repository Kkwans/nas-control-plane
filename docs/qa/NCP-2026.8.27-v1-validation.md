# NCP 2026.8.27-v1 验证记录

日期：2026-08-27

环境：`DH4300Plus` / `aarch64` / `/volume2/Project/nas-control-plane`
目标：NCP 第二轮产品化与工程质量收敛

本记录只写入已经取得的输出。NCP 仍是可信内网、登录后的 Root 控制面；本轮没有新增 MFA、RBAC、登录限流、复杂密码策略、CSP、路径 allowlist 或 Root/Docker 能力收紧。

## 已交付

- WP-A：页面巡检拆成独立 route/viewport 用例，CI 默认 2 workers；页面 readiness、异步卸载和 Infrastructure 刷新增加确定性等待。完整 Mock Playwright 已连续三次本地运行 `72 passed`。
- WP-B：补齐 `ListPath`、`GET /api/v1/files/entries`、Docker resources RPC/API、HostPath 浏览/高级手输、现有 network/volume 选择和创建前摘要；保留 Root 的 privileged/device/GPU/cap、argv 与随机端口能力。
- WP-C：按字段类型收敛 Database CellEditor，保留 `NULL`/`""` 与 bigint/decimal 文本精度；Logs 明确 bounded tail 与 cursor；Monitoring 统一状态、图表 token、温度 legend 和实时 merge。
- WP-D：统一站点/设置术语，迁移正式终端错误码并保留旧别名，统一危险确认、ResourceState、路由 focus 与设置恢复语义。
- WP-E：拆分 Agent 传输、Docker handler、站点图标、数据库 discovery、镜像/下载任务和容器创建映射；加入结构化 request log、ESLint/Prettier blocking gate、bundle budget、固定基础镜像与 gzip。
- WP-F：统一 `VERSION`/前端 package/Compose image/Go build version，创建 Git tag 与 GitHub Release，窄范围更新 NAS agent/server/console 并保留回滚点。

## Finding 处置

已解决并保留回归：COR-01、COR-02、REL-01、QA-01、QA-02、API-01、API-03、FE-04、FE-06、STATE-02、UX-01/02/07/09、DEP-01/03、WEB-01，以及 FE-03、BACK-01～04、REFACTOR-01 的已完成拆分切片。

当前实现更合理：Infrastructure 父组件继续拥有请求与 DNS/Mihomo 状态机；`api/system.ts` 保留兼容 facade；Docker 容器日志保持 bounded tail 并明确限制；前端暂用手写领域 DTO 加契约测试。

本轮延期：数据库 keyset pagination、Blob 下载新协议、全量 OpenAPI DTO 生成、站点 probe 缓存，以及没有测量依据的深度 bundle 重写。

取消/不适用：提高密码长度、MFA、RBAC、登录限流、CSP、same-origin middleware、路径 allowlist、Root Agent 权限收紧、Docker start 二次确认及其他安全加固。
