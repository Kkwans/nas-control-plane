## ADDED Requirements

### Requirement: 数据库实例工作区
数据库页面 MUST 使用真实实例清单展示类型、状态、镜像、端口、所属项目和数据目录，并提供搜索、引擎筛选与状态筛选。

#### Scenario: NAS 存在数据库容器
- **WHEN** 实例 API 返回一个或多个数据库
- **THEN** 用户可在首屏比较实例状态和关键运行位置

#### Scenario: 没有发现数据库实例
- **WHEN** 实例 API 返回空数组
- **THEN** 页面显示明确空状态，不创建演示实例或伪造在线状态

### Requirement: 数据库实例详情
用户 MUST 能打开实例详情查看完整镜像、容器状态、创建时间、项目、服务、全部端口和全部挂载。

#### Scenario: 用户打开实例详情
- **WHEN** 用户点击实例行或详情按钮
- **THEN** 页面打开详情抽屉并保留原列表位置

#### Scenario: 用户刷新详情链接
- **WHEN** URL 包含有效 `instance` 查询参数
- **THEN** 清单加载后自动恢复对应实例详情

### Requirement: 响应式数据库管理
数据库页面 MUST 在桌面使用高密度表格，在小于 768px 的视口使用无横向滚动的实例卡片和全屏详情。

#### Scenario: 手机用户查看数据库
- **WHEN** 视口宽度小于 768px
- **THEN** 页面使用卡片展示相同核心信息，并通过汉堡菜单进入数据库模块

### Requirement: 诚实表达能力边界
数据库页面 MUST 明确当前数据来自容器发现，且不得显示尚未实现的连接测试、库表管理、备份恢复或 SQL 操作按钮。

#### Scenario: 用户查看实例操作区
- **WHEN** 当前阶段只具备实例发现能力
- **THEN** 页面仅提供详情和端口信息，不提供无后端能力支撑的按钮
